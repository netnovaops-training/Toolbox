# How I keep this findable

So I can decide later what each thing did and whether it was useful, and find it
again fast.

## A status line at the top of each item
When I add something, I put a few lines on top I can edit LATER:

    # what: short description
    # status: trying | useful | not-useful
    # tags: networking, ssh, backup
    # last-used: 2026-10-15

I can change `status` and `last-used` any time (edit the file in the app, commit).

## Finding things again
- **Folders** group by topic (linux, security, ...). Start there.
- **Each folder's README** lists what's in it.
- **Search** in the GitHub app: open the repo, use the search box; it searches
  file names and text, so searching `useful` or `ssh` finds your tagged items.
- Optional: a GitHub **Project** board (To try / Useful / Retire) if I want a
  visual board — it lives in the repo and opens in the app.
