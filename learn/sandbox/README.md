# Sandbox

A safe place to practise. Nothing here matters, so break it freely.

Things to try (see the walkthrough homework):
1. Make a branch, change the line below, open a pull request, merge it.
2. Add a tiny GitHub Actions workflow that just prints "hello" and watch it run.
3. Make a change on two branches and practise a merge.

Practice line (edit me on a branch): the garden grows one commit at a time.
