# Toolbox — Jason A. Gibson

My own collection of useful scripts, shortcuts, docs and notes. One place,
versioned, backed up, and on every device.

## What's where
- **git/** — git commands and shortcuts I actually use.
- **scripts/** — small scripts (shell, python) I want handy.
- **cheatsheets/** — quick references.
- **notes/** — anything I'm learning and want to keep.

## Rules I keep
- One line at the top of each file saying what it does.
- If I copy something from someone else, I note where in SOURCES.md and keep
  their licence.
- Never commit secrets (keys, passwords, tokens). See .gitignore.
